# BUBT-SDP-Project-1

Common ANSI Color Codes:
| Code         | Color          |
| ------------ | -------------- |
| `\033[0m`    | Reset          |
| `\033[1;31m` | Bright Red     |
| `\033[1;32m` | Bright Green   |
| `\033[1;33m` | Bright Yellow  |
| `\033[1;34m` | Bright Blue    |
| `\033[1;35m` | Bright Magenta |
| `\033[1;36m` | Bright Cyan    |
| `\033[1;37m` | Bright White   |


File: 
1/ `ofstream` File e **write** korar jonno      
2/ `ifstream` File theke **read** korar jonno    
3/ `fstream`  File e **read & write** duto korte

Use:
Class	    Use
ofstream	File e write korar jonno
ifstream	File theke read korar jonno
fstream	    File e read & write duto korte

File modes:
ios::in → read mode
ios::out → write mode
ios::app → append mode (existing data delete na kore last e add)
ios::trunc → overwrite file (default write mode e)
